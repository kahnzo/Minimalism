# Developer Environment Notes

I have a goal of setting up a minimalistic developer environment to learn to code.  I don't want to spend too much time agonizing over whether I'm using the right tools, but I would like to have as few distractions as possible while I'm learning.

## Components

### The software components of my non-professional developer environment include:
- Operating System
- Terminal
- Shell
- Text Editor
- Database
- Compiler
- Debugger
- Version Control
- Automation
- Maintenance
- Continuous Integration and deployment
- Integrated Deveoper Environment (if I can make it minimalistic)

### Task Management
- To Do Lists
- Time management and tracking that is automated

### Hardware and Backend
- Local Machine
- Local Server
- Cloud Server
- Containers
- Hosting the database

###  The purpose of a developoment environment
- Code development and testing
- Security testing and reducing potential risks prior to production
- Early Error Detection
- Integration with larger systems
- Collaboration
- Staging and moving to production and the corresponding processes

## Discussion

Underlying philosophy is to reduce distractions but to balance that with having good tools.  A development environment for a individual who is learning to code can be dramatically different from someone that is working in the industry.
